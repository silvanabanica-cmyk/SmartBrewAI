# SmartBrew AI

## Overview
SmartBrew AI is a Python-based smart coffee shop application. It supports account management, drink ordering, ingredient inventory, recommendations, an assistant, simulated payments, order history, and technician functions.

## Features
- User accounts and login
- Drink customization and ordering
- Ingredient availability checks
- Custom recipes and recommendations
- AI-style assistant
- Simulated payment and receipt generation
- Order history
- Technician dashboard

## Requirements
- Python 3
- Dependencies, if any, required by the project

## Run the application
Run the following command from the project directory:
```powershell
python main.py
```

## Run tests
```powershell
python -m unittest discover -v
```

## Database
The application uses SQLite. Keep the database file in the project directory if the application depends on its existing data.
